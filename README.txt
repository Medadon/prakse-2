Prakse 11.11.2026 ir tīmekļa vietne par Maskavas apskates vietām un vienas dienas maršrutu.
Lapa veidota ar HTML, CSS un JavaScript, bet pieteikumu saglabāšanai izmantots Python serveris.
Lai apskatītu lapu, pārlūkā atver index.html; pieteikumu formai palaid py server.py un atver http://localhost:3000.
Budžeta kalkulators aprēķina ceļotāju, dienu, nakšu, naktsmītnes, ēdiena, transporta un izvēlēto pakalpojumu izmaksas.
